# Spec Template

Use this template for every new feature or behavior change.

```md
# <Feature Name>

## Goal
What problem this feature solves.

## Non-goals
What is intentionally out of scope.

## Scope
- Pages:
- APIs:
- Data:
- Permissions:
- Copy/text:

## User Flow
Describe the user journey or request flow.

## Data Changes
List new or changed fields, tables, payloads, or states.

## Acceptance Criteria
- Criterion 1
- Criterion 2
- Criterion 3

## Risks
- Risk 1
- Risk 2

## Rollback Plan
How to undo the change safely.

## Verification
- Test steps
- Screenshots or API responses

## Notes
Any decisions worth preserving for later.
```
